What Remains

A dark, first-person survival action RPG about death, stagnation and right to an ending.

This project is being made mainly for terra game. It´s in active development and it´s free for use to anyone for anything.
Current format is in ASCII in web, with no active webside. Future upgrades would include online web and much, much, much later upgraded graphics, probably to pixelart.

Main gimmick of this game is that it´s resources are finite, and that affects magic. That´s why "overlords" enslaved humanity during great war. But everything has an end, and this end is brought by main character.
